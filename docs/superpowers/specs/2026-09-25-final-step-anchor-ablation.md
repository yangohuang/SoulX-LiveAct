# Full-rollout ablation: omit the final velocity-anchor correction

## Hypothesis and scope

The [block-16 VAE replay](../../benchmarks/2026-09-25-hand-artifact-source-attribution.md) shows that the final denoising-step velocity correction is sufficient to create the visible hand smear under fixed prior history, in one offline eight-frame window. A full causal rollout may behave differently because changing that correction alters future generated-history and KV states. Test one narrowly defined intervention: keep the existing velocity anchor at all denoising steps except the **last**. This is a default-off ablation, not a claimed quality fix, a new diffusion algorithm, or SRF. The schedule and number of DiT forwards remain unchanged; only one anchor arithmetic call per later block is removed.

## Prespecified development case and gate

Generate identity 2, seed 43, first 30 seconds of audio 2, image 2, prompt `一个人在说话`, 416×720, 24 FPS, three denoising steps, strength 0.45 velocity mode, FP8 GEMM/KV, offload and one resident KV step. Compare to the archived same-input unanchored and all-step velocity videos, acknowledging cross-run stochastic variation. Validate 722 decoded frames. Review frames 500–507 and top five boundary-peak windows from each arm. Measure all 22 boundaries: immediate grayscale change, first-eight peak and motion sum. The development candidate only advances if the bright/dark hand smear is absent, no new conspicuous hand/face defect appears in reviewed windows, its mean local motion sum is at least 90% of the unanchored baseline, and matched-crop SyncNet relative confidence is no more than 0.20 below the baseline (baseline 6.955, minimum 6.755). Also report SyncNet minimum distance, best offset and pose-sensitive face-reference cosine/coverage without using cosine as a hard success criterion. These thresholds are feasibility filters for this case, not significance claims.

If the visual gate fails, stop before expensive SyncNet and held-out generation, record the negative result. If it passes visually, run the other metrics and then consider a held-out identity 3, seed 43, with the same predeclared motion/lip gate relative to its unanchored baseline. An improvement in one identity is insufficient for a default change or upstream PR; 30 seconds cannot establish infinite-video stability. The user's personal fork receives experiment evidence; official SoulX remains untouched.
