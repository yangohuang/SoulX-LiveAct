# Spatial source audit of the failed first-audio two-step motion gate

The [first-audio two-step ablation](../../benchmarks/2026-09-25-two-step-audio-conditioning.md) restored SyncNet confidence at seed 43 and seed 44, but the new seed-44 arm retained only 78.2% of the three-step baseline's full-frame grayscale change in 22 eight-transition chunk-boundary windows. This post hoc diagnostic asks **where** the missing image change lies. It cannot revise the preregistered gate failure or turn grayscale/flow into a human-motion quality score.

Analyze only the six already archived 416×720, 30-second image-2 videos: seeds 43/44 × three steps, stock two steps and first-audio two steps. Use decoded frames at 24 FPS, resize every frame to 104×180 grayscale and compute adjacent-frame absolute difference plus Farnebäck flow magnitude. Freeze these image-space regions before running comparisons: mouth `(x=36:68, y=37:64)`, upper-face/head `(x=25:79, y=8:82)`, lower-body/hand band `(x=0:104, y=105:180)`, and top outer-background corners `((x=0:20 or 84:104), y=0:70)` as a camera/background control. The mouth ROI and head ROI overlap by design and must never be summed; the lower-body band is separate. These fixed rectangles are rough scene-specific diagnostics, not landmark segmentation. Sample the same 22 chunk boundaries at transition indices `20 + 32k`, eight transitions each, as the original evaluator. Keep the full 721-transition timeline for an independent all-time check.

For each region, report per-arm all-time mean grayscale difference and optical-flow magnitude; mean eight-transition boundary-window sum and paired new/three-step ratio; count of 22 windows where the new arm is below baseline. Include stock-two controls to distinguish a general two-step effect from the first-audio change. Compare the whole-frame result against the existing `long_horizon_stability.py` output as a consistency check. Inspect representative frames and a region-overlay diagram to ensure regions land where intended. Use one synthetic moving-square unit test to show that lower-band motion is detected while stationary upper/background regions remain near zero, and one test for exact boundary-index extraction. Keep raw JSON, compact figure and script in the personal research branch. Do not select a new passing threshold or change the earlier rejection; state uncertainty from optical-flow errors, expression/pose changes and lack of true body landmarks.

**Exploratory triangulation added after the spatial audit:** the seed-44 lower-body flow is 0.886× baseline at boundary windows but 1.136× outside them, so global motion suppression is not established. MediaPipe Pose spot checks at frame 480 detect both elbows and wrists in the two seed-44 arms, with some wrist coordinates outside the frame. Run Pose on all six videos, record per-frame landmark visibility and coordinates, and compare displacement only on transitions where both paired arms have valid in-frame landmarks. Report coverage separately; do not select a new acceptance threshold or use pose results to reverse the original failed gate. This addendum is explicitly post hoc and descriptive.
