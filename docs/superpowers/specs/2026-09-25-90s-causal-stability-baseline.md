# 90-second causal stability baseline

Question: Does the existing unanchored LiveAct rollout show a measurable worsening with elapsed generation time, distinct from ordinary motion and pose changes?

Freeze identity 2, seed 43, first 90 seconds of source audio, 416×720/24 FPS, three denoising steps, FP8 GEMM/KV, CPU block/cache offload, one resident KV step, prompt `一个人在说话`. Use no latent anchor or probe. Preserve exact source/input hashes and generated MP4. Evaluate all complete eight-transition block windows and split into first, middle, last 30 seconds; measure immediate seam, delayed peak, window motion sum and severe-tail events. Sample a reference/first-face cosine once per second with detector coverage, but treat it as a pose-sensitive proxy, not an identity ground truth. Score audio synchronization on matched video/audio crop if the local SyncNet pipeline handles the long clip.

Predeclare an operational deterioration signal as a late-third median boundary peak at least 25% above early **while** late-third mean motion sum is at least 90% of early and face detection remains at least 90%. Peaks above the early-third 95th percentile are reported descriptively, not used as the binary gate. Before the 90-second result was available, a [calibration on six archived 30-second baselines](../../benchmarks/artifacts/2026-09-25-archived-30s-trend-calibration.json) showed that an event-count-or-median gate would fire in four of six 15-second comparisons, including examples where typical peaks fell; the median-only gate fired in one. This is a sensitivity check, not ground truth on whether those videos degraded. The detector condition is checked after the motion analysis. If the movement check fails, report an ambiguous change rather than temporal improvement/deterioration. Identity degradation requires a late-third reference and first-face cosine decrease of at least 0.05 with stable detector coverage and qualitative pose-aware review; cosine alone is insufficient. A single trajectory can identify a case, not a repeatable phenomenon. If the 90-second run succeeds within available resources, repeat unanchored identity 3/seed 43 for 60 seconds with the same analysis, keeping the unequal horizons explicit.

Do not make an infinite-video, training-time forcing, or real-time speed claim from this study. Stop on resource failure and report it; do not silently downscale. Sync evidence and code only to the personal fork; official SoulX PR requires user review.
