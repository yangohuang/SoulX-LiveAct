# Fixed-seed cross-process determinism diagnostic

Problem: two independently launched, same-seed/same-input LiveAct three-step pageable runs at 224×384 rendered videos with only 29.966 dB PSNR / 0.9284 SSIM, despite visually similar content. A pinned-versus-pageable comparison was no more different than this same-arm repeat. Earlier duplicate requests in one persistent process had matched pixel-for-pixel, so the discrepancy may be in process initialization, model conditions, a numerical kernel, or encoding. Do not assign cause based on seed placement alone: the active LightVAE encode returns the mean latent without sampling.

Run two new identical short, two-block 224×384/24-FPS processes using a 1.5-second audio excerpt, image 1, seed 42, the same three-step FP8/offload/cached setup, and no pinning. At the boundaries of preprocessing and generation, record tensor dtype/shape, SHA-256 of exact tensor bytes, and only lightweight scalar summaries: transformed reference image, CLIP embedding, resampled audio/Wav2Vec embedding, reference VAE latent, first generated noise tensor, each of six DiT inputs/outputs, VAE decode input/output, and final decoded video frame hashes. Use a wrapper/hook rather than changing model behavior; synchronize only for diagnostics. Record model/cache source fingerprints and exact invocation. Compare first divergence. One short per-process run is enough for source attribution if the same-run output discrepancy reproduces; if it does not, repeat once before drawing a conclusion.

Only after finding the first divergent boundary, test a single plausible mechanism with one controlled change. If the cause is a documented nondeterministic kernel or timing-sensitive transfer and forcing exact equality would materially harm speed/quality, report that trade-off without modifying default generation. If a small code defect is established, make a focused test and fix, then verify output and throughput. Do not reinterpret previous image-quality A/B results as deterministic pixel pairs until this audit is done. Keep artifacts local/personal fork only; no official SoulX PR without user review.
